# SIA Infinity ANCF WordPress v0.2 — Publisher Intelligence

v0.2 turns the SIA ANCF News theme into a newsroom integration shell while preserving the v0.1 safety principle that SEO authority, AI execution, monetization, and publishing actions live outside the theme.

## Separation of authority

```text
Theme        = newsroom interface
ANCF Core    = shared publishing metadata and governance
Rank Smart   = SEO authority
SIA AI       = translation / writing / paid intelligence
Brand Studio = monetization and sponsored-content workflow
```

The theme may display data from these systems, but it must not silently become their authority.

## Publisher Intelligence editor console

The post editor receives a `SIA Publisher Intelligence` panel with six read-only sections:

1. Content — Primary Semantic Silo, author, content type, editorial state.
2. URL Memory — whether URL Memory is active, observation count, last event, history signal.
3. Rank Smart — integration status and SEO-authority placeholder.
4. English / SIA AI — integration status, AI-assistance metadata, English-draft capability placeholder.
5. Discover Readiness — basic checks for a 1200px+ featured image, author identity, primary silo, and published state.
6. Monetization — commercial content mode plus Brand Studio integration status.

## Commercial content metadata

ANCF Core adds `_sia_commercial_type` with these values:

- `editorial`
- `sponsored_article`
- `guest_contribution`
- `brand_story`
- `existing_content_sponsorship`

This is classification only. v0.2 does not add paid links, disclosure markup, pricing, checkout, or marketplace actions.

## Integration contract

The theme exposes two extension points:

```php
apply_filters('sia_publisher_intelligence_context', $context, $post);
apply_filters('sia_publisher_integration_status', $integrations, $post);
do_action('sia_publisher_intelligence_after_sections', $post, $context);
```

Future Rank Smart, SIA AI, and Brand Studio modules should use these hooks instead of editing the theme directly.

## Safety invariant

v0.2 must not automatically:

- change a published URL;
- create or alter redirects;
- emit or replace canonical tags;
- change robots/indexing directives;
- replace another SEO plugin's schema or sitemap output;
- translate or overwrite article content;
- create an English draft without an explicit user action;
- add sponsored/paid links;
- publish sponsored or AI-generated content automatically.
