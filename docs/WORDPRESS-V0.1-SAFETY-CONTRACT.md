# WordPress v0.1 Safety Contract

1. No bulk URL mutation.
2. No automatic redirects.
3. No canonical output.
4. No robots/noindex output.
5. No XML sitemap takeover.
6. No structured-data takeover.
7. No automatic post deletion/merging.
8. No AI auto-publish.
9. No front-end related-post replacement.
10. All historical observations are append-only unless an administrator explicitly removes plugin data.

The purpose of v0.1 is to establish trustworthy memory before automation.
