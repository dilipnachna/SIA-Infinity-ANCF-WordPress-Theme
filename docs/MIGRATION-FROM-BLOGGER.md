# Shared concepts with SIA Infinity AI Blogger

The WordPress implementation preserves the Blogger project's architectural ideas while using native WordPress capabilities.

| Blogger concept | ANCF WordPress equivalent |
|---|---|
| First label = Primary Silo | Explicit primary WordPress category |
| Precomputed graph | WordPress-native relationship store (future) |
| Blogger feed fallback | WordPress database / REST API |
| Author box | User/entity profile model |
| Canonical template logic | SEO authority module (future, disabled v0.1) |
| Related recall | Semantic Intelligence module |

The goal is shared contracts, not copy-pasted platform logic.
